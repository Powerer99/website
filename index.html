    Explore the engineering context

    The need

    Starting a CI run for a branch, watching its logs, and tracing a failing test back to the code usually means switching between the IDE and a browser.

    What it does

    Detects the repository from the project's Git remotes, starts branch, custom, or workflow_dispatch runs with variables and inputs, streams step logs and test reports live, and links each failure straight to the right file and line. Runs can be stopped and revisited from history.

    Privacy by design

    BranchFuse has no server and no telemetry. Tokens live only in the IDE's password safe and are sent only to Bitbucket or GitHub.
